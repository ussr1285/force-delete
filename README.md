# force-delete

"다른 프로세스가 사용 중이라 삭제할 수 없습니다"가 뜨는 폴더나 파일을 지우는 Windows 도구.
잡고 있는 프로세스를 찾아서 보여 주고, 확인을 받은 뒤 종료하고 삭제한다.

탐색기는 어떤 프로그램이 잡고 있는지 알려 주지 않는 경우가 많다. 특히 폴더 자체를 잡고 있는 경우
(파일 열기 대화상자로 한 번 들어갔던 폴더, cmd/터미널의 현재 경로 등)는 리소스 모니터나
Restart Manager로도 안 보인다. 이 도구는 시스템 핸들 테이블을 직접 훑어서(Sysinternals `handle.exe`와
같은 방식) 그런 경우까지 찾는다.

## 필요한 것

- Windows 10 / 11
- Windows PowerShell 5.1 (기본 포함). 설치할 것 없음

## 사용법

### 끌어다 놓기

지울 폴더나 파일을 `force-delete.bat` 위로 끌어다 놓는다. 여러 개도 된다.

### 실행해서 경로 입력

`force-delete.bat`을 더블클릭하면 경로를 묻는다. 경로를 붙여 넣거나 탐색기에서 창으로 끌어다 놓고 엔터.

### 명령줄

```
force-delete.bat "D:\tmp\locked"              폴더째 삭제 (확인 질문 있음)
force-delete.bat "D:\tmp\locked" -ListOnly    누가 잡고 있는지만 보기 (아무것도 안 지움)
force-delete.bat "D:\tmp\cache" -KeepRoot     폴더는 남기고 안의 내용만 삭제
force-delete.bat "D:\tmp\locked" -Yes         확인 질문 없이 진행
```

PowerShell에서 바로 `.\force-delete.ps1 <경로> [옵션]`으로 실행해도 된다.

## 동작 순서

1. 대상 확인 — 파일 개수와 용량을 보여 준다.
2. 잠금 프로세스 찾기 — 세 가지를 합친다.
   - 시스템 핸들 테이블: 그 경로 아래 파일·폴더 핸들을 가진 프로세스
   - Restart Manager: 파일을 사용 중인 프로그램 (메모리에 매핑된 DLL 등)
   - 그 경로 안의 exe로 실행 중인 프로세스
3. 확인 — `Y`(또는 한글 자판 `ㅛ`)를 눌러야 진행한다.
4. 그 경로를 열고 있는 탐색기 창을 닫고, 잠금 프로세스를 강제 종료한다.
5. 삭제 — 읽기 전용/숨김/시스템 속성을 풀고 지운다. 안 지워지면 차례로 시도한다.
   - .NET 삭제 (`\\?\` 경로라 260자 넘는 경로, 끝에 점·공백이 붙은 이름도 처리)
   - 빈 폴더로 `robocopy /MIR` 후 `rd /s /q`
   - 관리자 권한이면 `takeown` + `icacls`로 소유권을 가져온 뒤 다시 시도
6. 그래도 남으면
   - 탐색기가 잡고 있으면 탐색기 재시작을 제안
   - 관리자가 아니면 관리자 권한으로 다시 실행을 제안
   - 관리자여도 안 되면 다음 재부팅 때 삭제하도록 예약을 제안

**휴지통을 거치지 않고 영구 삭제한다.** 되돌릴 수 없다.

## 건드리지 않는 것

다음 경로는 그 자체나 그 상위 폴더를 지우려 하면 거부한다.

- 드라이브 루트 (`C:\`, `D:\` …)
- `Windows`, `Program Files`, `Program Files (x86)`, `ProgramData`
- 사용자 폴더 (`C:\Users\<이름>`), `AppData`, 바탕 화면, 문서, 다운로드, 사진, 음악, 동영상, OneDrive
- 이 도구가 들어 있는 폴더

그 아래의 하위 폴더(예: `다운로드\옛날자료`)는 지울 수 있다.

다음 프로세스는 잡고 있어도 종료하지 않는다. 대신 알려 준다.

- 시스템 프로세스: `csrss`, `lsass`, `services`, `svchost`, `dwm`, `MsMpEng`(Defender), `SearchIndexer` 등
- 탐색기(`explorer`): 창만 닫고, 그래도 안 되면 재시작할지 묻는다
- 이 도구를 실행한 cmd/터미널 창: 현재 경로가 대상 안에 있으면 다른 폴더로 `cd` 하라고 알려 준다

## 주의

- 강제 종료된 프로그램의 저장 안 한 작업은 사라진다. 목록에 편집 중인 프로그램(Word, PowerPoint 등)이
  보이면 먼저 직접 저장하고 닫는 게 안전하다.
- 관리자 권한으로 실행 중인 프로그램이나 다른 사용자의 프로세스는 일반 권한으로는 보이지 않거나 종료되지
  않을 수 있다. 이때는 관리자 권한으로 다시 실행하면 된다.
- 끌어다 놓을 때 경로에 `&` 같은 cmd 특수문자가 있고 공백이 없으면 bat이 경로를 잘못 읽는다.
  그럴 땐 bat을 더블클릭해서 경로를 직접 입력한다.
